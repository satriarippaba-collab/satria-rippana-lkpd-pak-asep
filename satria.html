Variable dapat dianggap sebagai tempat untuk menyimpan sebuah data agar data tersebut dapat digunakan kembali oleh program.

Dapat dibayangkan seperti sebuah kotak bernama nama yang menyimpan nilai "Andi".

JAktivitas 6 — Mengenal let dan const

Perhatikan kode berikut:

let umur = 16;
umur = 17;
console.log(umur);

Hasil:

17, karena nilai variable yang dibuat dengan let dapat diubah.

Sekarang coba:

const nama = "Budi";
nama = "Andi";
console.log(nama);

Apa yang terjadi?

Program menghasilkan error karena variable yang dibuat dengan const tidak dapat diberi nilai baru melalui assignment seperti itu.

Kesimpulan Sementara

KeywordNilai dapat diubah?Kegunaan sederhana
letYaUntuk data yang mungkin berubah.
constTidak, tidak dapat di-assign ulangUntuk data yang tidak perlu diganti nilainya.

Ingat! Gunakan let untuk data yang masih mungkin berubah, contohnya:

let nilai = 80;
nilai = 90;

Gunakan const untuk data yang tidak perlu diubah, contohnya:

const namaSekolah = "SMK";

KAktivitas 7 — Aturan Penamaan Variable

Perhatikan nama variable berikut:

let nama;
let namaSiswa;
let nama_siswa;
let umur2;

Diperbolehkan:

let nama;
let namaSiswa;
let nama_siswa;
let nilai1;

Tidak diperbolehkan:

let 1nama;
let nama siswa;
let nama-siswa;

JavaScript membedakan huruf besar dan kecil (case-sensitive).

let nama = "Andi";
console.log(nama); // menampilkan Andi
console.log(Nama); // error karena Nama berbeda dari nama

OAktivitas 11 — Debugging

Program berikut memiliki beberapa kesalahan.

let nama siswa = "Budi";
let umur = 16;
let 2kelas = "XI RPL";

console.log(nama siswa);
console.log(umur);
console.log(2kelas);

Program yang sudah diperbaiki:

let namaSiswa = "Budi";
let umur = 16;
let kelas2 = "XI RPL";

console.log(namaSiswa);
console.log(umur);
console.log(kelas2);
  
  
Apa saja kesalahan yang ditemukan?
  1. Nama variable nama siswa mengandung spasi; gunakan namaSiswa.
  2. Nama variable 2kelas diawali angka; gunakan kelas2.
  3. Perintah console.log() juga harus menggunakan nama variable yang sudah diperbaiki.
